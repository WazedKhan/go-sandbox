# Katas

Small drills from The Engineer roadmap. One folder per roadmap day (`w1d1` = week 1, day 1).

How to work a kata:

1. Read the kata README. No AI, no docs for the first attempt.
2. Run the tests and watch them fail: `go test -race ./w1d1-map-aggregate/`
3. Fix the code until they pass. Don't edit the tests.
4. Answer the "Explain it" questions in your own words.
